## Working addition: project record workbench

`project-workbench.html` and `shared/project-workbench.js` provide a real, interactive **offline metadata editing tool**, reachable from `review.html`:

- Choose Academy `.org` or production `.com` as **separate project record surfaces**.
- Edit record ID, title, discipline, summary, verified credits, referenced asset IDs, and internal draft/review stage.
- Live, safely text-rendered preview (no user content inserted as HTML).
- Validation for IDs, title, surface, category, asset IDs, duplicate references and draft/review stage.
- Import existing JSON **from a local file**. All imported records are forcibly downgraded to `draft`; imported approval fields and `approved_public` claims are discarded.
- Export schema-compatible `.draft.json` for a developer/editor handoff. Output approval remains `approved_by: null`, `approved_at: null`, `rights_verified: false`. No data is submitted to a server, written to public pages, or sent to either domain.
- No `localStorage` persistence; use Export to keep a copy. No external libraries or network dependencies.

This is a **content preparation tool**, not an approval system. A valid record is NOT a published or rights-cleared record. References to asset IDs are not evidence that media files exist or are licensed.
